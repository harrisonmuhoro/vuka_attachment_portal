# API Endpoint Inventory

**Audit Basis:** Local codebase at commit `83aa34f`.  
**Total API Endpoints:** 46 endpoints located under `/api/`.  
**Authentication Standard:** Bearer token (`Authorization: Bearer <token>`) passed via HTTP headers or fallback cookie `session_id`, validated against the `sessions` table via `session-manager.php`.

## Architectural Findings & Patterns Across API

1. **Authorization Gate Inconsistency:**
   - Most endpoints contain authentication or role guards, but the table records important exceptions and conditional access paths; endpoint-by-endpoint authorization verification is required before production.
   - 2 endpoints have catastrophic authorization bypasses (`api/get-submissions.php` and `api/update-submission.php`).
   - 1 endpoint allows unauthenticated submission on behalf of existing users (`api/submit-application.php`).
   - `api/get-audit-log.php` allows department supervisors but does not apply the department scope it calculates (SEC-11).
   - 7 endpoints are intended to be public (`login.php`, `admin-login.php`, `student-login.php`, `register.php`, `verify-email.php`, `forgot-password.php`, `reset-password.php`). `submit-application.php` is also public by design, but permits submission using another user’s National ID and requires a product-policy decision and ownership control.

2. **Session Creation Discrepancies:**
   - `student-login.php` uses `SessionManager::createSession()`.
   - `login.php` and `admin-login.php` perform manual SQL `INSERT INTO sessions` omitting standard timestamp fields.

3. **Response Envelope Standardization:**
   - Most endpoints utilize `json_response($success, $data, $message, $httpCode)` from `config/config.php`.
   - Some endpoints (`change-password.php`, `confirm-email-change.php`, `update-admin-profile.php`, `update-student-profile.php`) emit ad-hoc `echo json_encode(...)` with varying keys (`error` vs `message`).
   - Binary endpoints (`download-document.php`, `serve-profile-photo.php`, `generate-letter.php`, `generate-evaluation-pdf.php`) correctly bypass JSON buffers to stream bytes directly.
